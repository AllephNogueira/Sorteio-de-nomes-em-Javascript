# 🎲 Aplicativo de Sorteio de Nomes


![Imagem apresentação do projeto](https://github.com/AllephNogueira/Sorteio-de-nomes-em-Javascript/blob/main/pagina.png)

Um aplicativo web simples e moderno para sortear nomes aleatoriamente.

## 📋 Funcionalidades

- ✅ Adicionar nomes à lista
- ✅ Remover nomes individuais
- ✅ Limpar toda a lista
- ✅ Sortear um nome aleatório com animação
- ✅ Salvar automaticamente no navegador (localStorage)
- ✅ Interface moderna e responsiva

## 🚀 Como usar

1. Abra o arquivo `index.html` no seu navegador
2. Digite um nome no campo de texto
3. Pressione Enter ou clique em "Adicionar"
4. Repita para adicionar mais nomes
5. Clique em "🎯 Sortear" para sortear um nome aleatório

## 💡 Recursos

- **Animação de sorteio**: Efeito visual durante o sorteio
- **Persistência**: Os nomes são salvos automaticamente no navegador
- **Validação**: Não permite nomes duplicados ou vazios
- **Design responsivo**: Funciona bem em diferentes tamanhos de tela

## 📁 Arquivos

- `index.html` - Estrutura HTML
- `style.css` - Estilos e design
- `script.js` - Lógica do aplicativo

## 🎨 Tecnologias

- HTML5
- CSS3
- JavaScript (Vanilla)
